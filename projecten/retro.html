01 / INTRODUCTIE

Oud is
weer nieuw.

Voor het project Digital Garden kregen we de opdracht om een eigen digitaal tuintje te maken rondom een onderwerp dat ons interesseert. Ik koos voor de terugkeer van retro.

Toen ik net verhuisd was, zocht ik naar meubels voor mijn kamer. Daarbij viel het me op hoeveel retro- en vintageproducten ik tegenkwam. Er kwamen steeds meer winkels voorbij die zich specialiseerden in tweedehands en retro spullen. Dat bracht me op de vraag waarom retro weer zo populair lijkt te worden. Het viel mij niet alleen in interieur op, maar ook in posters, kleuren, typografie, mode en grafisch ontwerp. Ik wilde een website maken waarin je die verschillende stijlen door de tijd heen kunt ontdekken. Een plek waar oude ontwerpen opnieuw tot leven komen.

02 / ONDERZOEK

alles
retro.

In mijn eerste onderzoek keek ik breed naar de terugkeer van retro. Ik verzamelde voorbeelden van interieur, kleurgebruik, typografie en grafisch ontwerp. Vooral posters trokken mijn aandacht.

Visuele inspiratie.

03 / CONCEPT

Terug naar
de posters.

Mijn eerste idee was nog behoorlijk breed. Ik wilde allerlei vormen van retro samenbrengen op één website. Tijdens het onderzoek merkte ik dat ik vooral veel voorbeelden van retro-interieur vond.

Na overleg met mijn docent besloot ik me te richten op posterstijlen. Daardoor kon ik de verschillen tussen de periodes duidelijk laten zien en kreeg het concept een concretere richting. Dit heeft mij veel geholpen om vervolgens hierop door te gaan.

04 / WEBSITE

Elke tijd
zijn eigen stijl.

Ik wilde de bezoeker meenemen door verschillende decennia. Iedere periode kreeg daarom een eigen lettertype, kleurgebruik en teksteffect. Die keuzes zijn geïnspireerd op de kenmerken van de posters uit die tijd.

Ik bouwde de website met HTML en CSS. Dit was pas de tweede keer dat ik hiermee werkte. Ik wilde vooral experimenteren met wat CSS allemaal mogelijk maakt. De grote typografie en scrollanimaties moesten de website meer beweging en een verrassend effect geven.

De verschillende periodes met hun eigen typografie en uitstraling.

05 / MOBILE FIRST

mobile
first.

Vooral het werken met CSS Grid en de scrollanimaties vond ik uitdagend. Het "mobile first" ontwerpen was ook lastig, ik gebruikte media queries en clamp() om de website op verschillende schermformaten te laten werken. Op kleine schermen stapelen de onderdelen zich onder elkaar. Omdat hover niet werkt op een touchscreen, heb ik die effecten bij een klein scherm op scrollen laten reageren."

06 / TOEGANKELIJKHEID

Niet alleen
voor de show.

Naast de vormgeving heb ik ook aandacht besteed aan toegankelijkheid. Ik testte de website onder andere met een screenreader, toetsenbord, en Colorblindly. Ook was het belangrijk dat de website een reduced motion en hoger contrast functie ondersteunt. Daarbij kwam ik verschillende verbeterpunten tegen, zoals ontbrekende focusstijlen en een betere HTML structuur.

Instellingen voor hoog contrast en minder beweging kregen een eigen uitwerking.

07 / COOKIES & DARK PATTERNS

cookies.

Tijdens het project onderzocht ik ook wat de toestemming voor cookies nou eigenlijk betekent voor de gebruiker. Ik leerde hoe websites gebruikers kunnen sturen richting een bepaalde keuze, bijvoorbeeld door accepteren makkelijker of aantrekkelijker te maken dan weigeren.

Ik heb dit zelf op een opvallende manier toegepast. Als je cookies weigert, krijg je een lelijke versie van mijn website te zien.

De versie van de website die de gebruiker krijgt als hij/ zij op deny heeft geklikt.

08 / TERUGBLIK

Wat ik
meeneem.

Dit project was mijn tweede keer werken met HTML en CSS. Ik heb veel geëxperimenteerd en vooral geleerd door dingen uit te proberen, grid, scrollanimaties en responsive design vond ik in het begin lastig, maar uiteindelijk kreeg ik steeds meer verstand van de code.

Ik ben vooral tevreden met hoeveel beweging en stijl ik in de website heb gekregen. De animaties kostten veel tijd, maar maakten het resultaat voor mij echt af. Ook heb ik geleerd om een website vanaf het begin responsive en toegankelijk op te bouwen.
