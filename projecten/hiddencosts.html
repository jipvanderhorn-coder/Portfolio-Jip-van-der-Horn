01 / PROJECT · WIJZER OP HET WEB

Hidden Costs.

2026

01 / INTRODUCTIE

Het lijkt
goedkoper.

Voor het project Wijzer op het web in blok 2 van jaar 1 onderzocht ik het misleidende ontwerppatroon Hidden Costs. Dat gaat bijvoorbeeld over bijkomende kosten bij het boeken van een hotel of het bestellen van een ogenschijnlijk 'goedkoop' product.

Ik bekeek verschillende websites om te ontdekken hoe dit werkt. Een van de voorbeelden die ik onderzocht was Booking.com. Mijn standpunt hierover was duidelijk: dat moet anders.

Na dit onderzoek kregen we de opdracht om campagne te voeren tegen dit dark pattern. Dit deden we met posters, een opiniestuk en een website.

02 / ONDERZOEK

Hoe vaak
gebeurt dit?

Om te kijken hoe vaak mensen zelf met Hidden Costs te maken hebben gehad, maakte ik een vragenformulier. Ongeveer twintig mensen vulden dit in. Opvallend was dat 100% aangaf hier weleens mee te maken te hebben gehad.

100%

van de respondenten had weleens te maken gehad met Hidden Costs.

De onderzoeksresultaten, uitgewerkt in Illustrator.

03 / OPINIESTUK

Een mening
op papier.

Met mijn onderzoek als uitgangspunt schreef ik een opiniestuk over Hidden Costs en de invloed hiervan op de keuzevrijheid van gebruikers.

Voor de vormgeving maakte ik een aantal verschillende ontwerpen. Ik experimenteerde met typografie, compositie en kleurgebruik om te ontdekken hoe ik mijn boodschap het beste kon overbrengen. Uiteindelijk kwam ik uit bij de kleuren zwart, wit en rood. Deze combinatie werd de basis voor de rest van de campagne.

Een overzicht van al mijn opiniestuk ontwerpen.

04 / CAMPAGNE

Dat moet
anders.

Naast het opiniestuk maakte ik propagandaposters om campagne te voeren tegen dit dark pattern. Hiervoor experimenteerde ik flink met verschillende ontwerpen. In totaal maakte ik ongeveer veertig posters, waarvan ik er vier selecteerde voor mijn portfolio.

Ik werkte met grote, dikke letters en een uitgesproken typografische stijl. De posters kregen ieder een eigen uitwerking, maar sloten door het kleurgebruik en de vormgeving op elkaar aan.

05 / WEBSITE

Van Illustrator
naar code.

Als afsluitend onderdeel bracht ik de verschillende onderdelen samen in een campagnewebsite. Ik begon met het ontwerpen van de website in Illustrator, waarbij ik de visuele stijl van de campagne doortrok.

Daarna bouwde ik de website met HTML en CSS. Dit was de eerste keer dat ik met code werkte en zelf een website bouwde. Na het omzetten van mijn ontwerp naar een werkende website experimenteerde ik met hoverinteracties en scrollanimaties. Ik leerde hoe HTML en CSS samenwerken en hoe ik met animaties meer beweging en levendigheid aan een website kan toevoegen.

Het eerste (langwerpige) voorbeeld was mijn eerste idee, één lange statische scroll met alle tekst in dezelfde stijl als mijn opniniestuk. Nadat ik leerde over wat css allemaal kon ben ik nieuwe ontwerpen in illustrator gaan maken met de mogelijkheden van scroll effecten in mijn achterhoofd (de afbeelding met meerdere schermen).

Daarna heb ik dat laatste ontwerp uitgewerkt in HTML CSS waarbij de grote woorden in de pagina reageren op de scroll van de gebruiker.

06 / TERUGBLIK

Wat ik
meeneem.

Dit project was voor mij een eerste kennismaking met het maken van een volledige campagne en het bouwen van een website. Ik heb veel geëxperimenteerd met typografie en vormgeving, maar ook voor het eerst zelf een ontwerp met HTML en CSS gemaakt.

Het leuke aan dit project vond ik de combinatie van grafisch ontwerpen en coderen. Er was veel ruimte voor creativiteit en ik heb hiervan veel geleerd.
